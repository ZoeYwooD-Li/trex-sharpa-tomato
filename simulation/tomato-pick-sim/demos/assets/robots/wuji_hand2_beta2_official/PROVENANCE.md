# Wuji Hand 2 Beta2 official assets

This directory contains the unmodified Wuji Technology Hand 2 Beta2 left and
right `with_mount` MJCF models and every mesh referenced by those models.

- Source: <https://github.com/wuji-technology/wuji-description>
- Revision: `4c1073d0a3ad1daaf6546d219db751d8448d3888`
- Models: `mjcf/left_with_mount.xml`, `mjcf/right_with_mount.xml`
- License: MIT; see `LICENSE.txt`.

The cherry-tomato task uses the five authored fingertip sensor-pad meshes and
five distal-link collision meshes per hand. The files themselves are kept
unchanged so their coordinate, joint, and mounting contracts remain auditable.
